1️⃣ What is the difference between var, let, and const?
Ans:Difference between var, let, const are-
1.var is old way, global scope, can change and re-declare.  
2.let is modern but block scope, can change but not re-declare.  
3.const is block scope and it cannot change after set but objects/arrays can still be edited.
